<h1>OSPF command</h1>

initializes the OSPF process.
<br>
<b>router ospf process-id</b>

<h2>under OSPF process</h2>
<br>
<b>router-id router-id</b>
<br>

makes the interface passive
<br>
<b>passive interface-id under the OSPF</b> 
<br>

makes all interfaces passive.
<br>
<b>passive interface default</b>
<br>

advertise the default route
<br>
<b>default-information originate [always] [metric metric-value] [metric-type type-value] </b>
<br>

Plaintext authentication  enabled
<br>
<b>area area-id authentication</b>
<br>

MD5 authentication enabled 
<br>
<b>area area-id authentication message-digest. </b>
<br>

<h2>under interface</h2>

Setting an interface priority
<br>
<b>ip ospf priority <0-255></b>
<br>

sets an interface as an OSPF broadcast network type
<br>
<b>ip ospf network broadcast</b>
<br>

sets an interface as an OSPF nonbroadcast network type.
<br>
<b>ip ospf network non-broadcast</b>
<br>

Neighbors are statically defined
<br>
<b>neighbor ip-address</b>
<br>

Set The OSPF network type point-to-multipoint
<br>
<b> ip ospf network point-to-multipoint </b> 
<br>

The OSPF hello timer is modified with
<br>
<b>ip ospf hello-interval 1-65,535.</b>
<br>

change the OSPF dead interval 
<br>
<b>ip ospf dead-interval 1-65,535</b>
<br>

sets plaintext authentication only on that interface.
<br>
<b> ip ospf authentication</b>
<br>

plaintext password is configured
<br>
<b>ip ospf authentication-key password</b>
<br>

sets MD5 authentication for that interface
<br>
<b>ip ospf authentication message-digest</b>
<br>

sets the MD5 password.
<br>
<b>ip ospf message-digest-key key-number md5 password</b> 
<br>


<h2>view</h2>

the process of forming an adjacency (detailed information for all of the states)
<br>
<b>debug ip ospf adj debug ip ospf adj</b>
<br>

OSPF-enabled interfaces
<br>
<b>show Ip ospf interface [brief </b> | interface-id].
<br>

The network type 
<br>
<b>show ip ospf interface | include Type</b>
<br>

Verifying OSPF Timers
<br>
<b>show ip ospf interface | i Timer|line</b>
<br>

provides the OSPF neighbor table
<br>
<b>show ip ospf neighbor [detail]</b> 
<br>

display OSPF routes 
<br>
<b>show Ip route ospf</b>
<br>

Verifying authentication 
<br>
<b>show ip ospf interface | i line|authentication </b>
<br>

OSPF LSAs 1
<br>
<b>show ip ospf database router</b>
<br>

OSPF LSAs 2
<br>
<b>show ip ospf database network</b>
<br>

Type 3 LSAs 
<br>
<b>show ip ospf database summary</b>
<br>

Type 5 LSAs in detail 
<br>
<b>show ip ospf database external</b>. 
<br>

Type 4 LSAs
<br>
<b>show ip ospf database asbr-summary</b>
<br>

Type 7 LSA 
<br>
<b>show ip ospf database nssa-external<b>
